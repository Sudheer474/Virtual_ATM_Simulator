##💳 Virtual ATM Simulator (Spring Boot)

This is a backend simulation of an ATM system using Spring Boot, Java, and MySQL.

##Core Entities
- User
- Account
- Card
- Transaction

##Tech Stack
- Java 17
- Spring Boot 3.x
- Spring Data JPA
- MySQL
- Lombok

##How to Run
1. Update your 'application.properties' with your MySQL credentials.
2. Run 'mvn spring-boot:run' or use IntelliJ run button.
3. Verify DB tables are created.
